# IRḶOḶI Technologies — Company Website

This repository is being rebranded from a personal portfolio into the IRḶOḶI Technologies company website.

## Stack
- Static HTML
- CSS
- Vanilla JavaScript
- Google Fonts (DM Sans and Manrope)

No build step or package installation is required.

## Run locally
Open `index.html` in a browser, or serve the folder with any static web server.

## Deploy
The site is compatible with GitHub Pages and other static hosting providers. The current company redesign is on the `company-rebrand` branch. Review and merge it into `main` before expecting the existing GitHub Pages deployment to change.

## Project links
Portfolio cards link to live demos when a demo URL is known, otherwise to the corresponding GitHub source repository. Repository links are not presented as live deployments.
